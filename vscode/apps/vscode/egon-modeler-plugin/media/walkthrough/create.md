# Create your first domain story

A **domain story** shows how people actually work together: *actors* (people or systems)
doing *activities* with *work objects* (documents, messages, things), told as a numbered
sequence you can read like a sentence.

To start one:

1. Click **[New file](command:workbench.action.files.newUntitledFile)** (or use
   **File > New File…**).
2. Press `Ctrl/Cmd+S` and save it with the `.egn` extension, for example
   `my-first-story.egn`.

VS Code opens the file straight into the **Egon.io** graphical editor. The `.egn` file is
plain text (JSON), so it stays the source of truth — save, Git, and diff all keep working.

Already have a `.egn` file? Just open it and the modeler appears automatically.
